# maimai-rating-tool
# maimai レート計算サポートツール

maimaiでらっくすの **DX Rating（レーティング）** を計算・管理するための、ブラウザだけで動くシングルファイルのWebツールです。
URLはこちら→　https://rinkaidaigakusei.github.io/maimai-rating-tool/maimai-app.html

スクリーンショットを生成AI（Gemini / ChatGPT / Claude）に読み取らせて曲一覧を取り込み、新曲枠/旧曲枠ごとのレート合計や目標レートまでの進捗を自動計算します。さらに「この曲を伸ばしたら／追加したら、レートはどう変わるか？」を試せるシミュレーション機能も搭載しています。

> ⚠️ 本ツールは個人が独自に作成した非公式の計算補助ツールです。SEGA・maimaiでらっくす公式とは一切関係ありません。算出されるレート・定数はあくまで試算であり、実際のゲーム内表示と異なる場合があります。

## 🔗 使ってみる

`maimai-app.html` をブラウザで開くだけで動作します（インストール不要）。

- ファイルをダウンロードしてダブルクリックで開く
- もしくは GitHub Pages 等で公開されているURLにアクセスする

データはお使いのブラウザ内（localStorage）に自動保存されるため、リロードしても消えません。

## ✨ 主な機能

### 1. スクリーンショットからの曲一覧取り込み
- **Gemini APIキーをお持ちの方**：画像を選択して「読み取り開始」を押すだけで、OCRにより曲名・難易度・達成率を自動抽出します（クォータ切れ時はOpenAI/Claudeへの自動フォールバックにも対応）
- **APIキーをお持ちでない方**：スクリーンショットと一緒に貼り付けるだけで使える「指示文（プロンプト）」を用意しています。Gemini・ChatGPT・ClaudeなどのWebチャットにスクリーンショットと一緒に貼り付けて送信し、出力されたCSVをツールに貼り付けるだけで取り込めます
  - 「あならいざもどき2」など、譜面定数が画像に表示されているスクリーンショット用
  - 「プレイヤーデータ」画面（RATING対象曲一覧）など、譜面定数が表示されておらず「LEVEL（9+/10など）」だけの画像用（AIにWeb検索で現在の定数を調べてもらう指示文）

### 2. 新曲枠/旧曲枠の自動集計
- 取り込んだ曲を自動で新曲枠（最大15曲）・旧曲枠（最大35曲）に振り分け、レート合計・総DX Ratingを計算
- 枠ごとに目標レートを設定すると、達成までの差分を表示
- 全体の目標レーティング（段位プリセット or カスタム値）に対する進捗バー・戦略メモも表示

### 3. 単曲レート計算 ＆ 手動追加
- 曲名・難易度・達成率を入力するだけで、その場でレートを試算
- 譜面定数が分からない場合は、
  - 🔍 Googleで定数を検索（gamerchの該当ページを新しいタブで開く）
  - 🤖 Geminiなどのチャットに定数を聞くための質問文をワンクリックでコピー（**APIキー不要**）
  
  のいずれかで調べられます
- 結果はそのまま実際の集計に追加できます

### 4. シミュレーション（「もしこの曲を入れたら？」）
現在の集計をコピーした「page-within-page」のシミュレーション画面で、実際のデータに影響を与えずに試行錯誤できます。

- 曲の追加・削除、達成率の編集（S / S+ / SS / SS+ / SSS / SSS+ ボタンでワンクリック入力）
- 既存の収録曲の達成率も編集して「あと何%伸ばせばレートがいくつになるか」を試算
- 譜面定数ごとの「ランク別レート目安表」を計算
- 新曲枠/旧曲枠それぞれに候補曲・代替曲のメモ欄、曲ごとのメモ欄
- 編集・追加した曲は色付きハイライトで一目で分かる
- 変更内容は「リセット」を押すまで保持（モーダルを閉じても消えません）
- シミュレーション結果は
  - 📄 再取り込み可能なテキストとして保存
  - 🖼️ スマホでも見やすい表形式のPNG画像として保存
  
  のどちらでも出力できます（保存したテキストは後から読み込んで復元することも可能）

### 5. データの自動保存
- 確定済み曲一覧・目標レート・シミュレーションの内容は、ブラウザのlocalStorageに自動保存されます
- リロードしても消えず、続きから作業できます
- 「保存データを消去」ボタンでいつでもリセット可能

## 🖥️ 動作環境

- 最新のデスクトップ／モバイルブラウザ（Chrome, Safari, Edge など）
- スマートフォンでも操作できるようレイアウトを最適化しています
- サーバー不要・追加インストール不要（HTMLファイル単体で完結）

## 🔑 APIキーについて

OCR機能や定数自動検索を使う場合は、以下のいずれかのAPIキーを設定できます（すべて任意・無くても主要機能は利用可能です）。

- Gemini APIキー
- OpenAI APIキー
- Anthropic (Claude) APIキー

APIキーはブラウザ内で入力欄に保持されるだけで、ツール制作者や第三者のサーバーに送信されることはありません（各AIサービスへの通信のみ発生します）。

## 📋 注意事項

- 本ツールで算出される譜面定数・レートは、Web検索やAIの知識による**試算・参考値**です。最新バージョンの公式情報と異なる場合があります
- 自動保存されるデータは、**お使いのブラウザ・端末ごと**に保存されます（クラウド同期はされません）。別の端末・別のブラウザを使う場合は、テキスト保存機能を使ってデータを引き継いでください
